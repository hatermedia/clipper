How to batch trim ShadowPlay clips automatically

ShadowPlay is great at capturing everything. It is terrible at telling you which 30 seconds mattered. This guide shows a local workflow that scans a folder of clips, finds the loud and fast-moving moments, and exports a trimmed pack without uploading anything.

The problem with manual trimming

If you record a four-hour session, you might end up with 30–80 separate clips. Scrubbing each one, finding the fight, setting in/out points, and exporting is death by a thousand cuts. Most editors solve it with a timeline and a lot of coffee. A clipper solves it with signal processing.

The trick is not “AI understanding.” It is simpler: gunfights and reactions are loud, explosions and camera flicks are visually busy, and quiet downtime is neither. Score both, merge the overlapping windows, and cut.

Step 1 — Install FFmpeg and Clipper

Clipper is a Python CLI with a local web UI. You need Python 3.10+ and FFmpeg on PATH.

# Windows
winget install Gyan.FFmpeg

# macOS
brew install ffmpeg

# Ubuntu / Debian
sudo apt install ffmpeg

Windows shortcut: the native zip bundles Python, PySide6, and FFmpeg. Unzip it, double-click Clipper.exe, and skip the source install. Download the native app.

Otherwise install the current release wheel:

python -m pip install https://github.com/hatermedia/clipper/releases/download/v0.2.1/clipper_gg-0.2.1-py3-none-any.whl

Or install straight from the repository with pipx:

pipx install git+https://github.com/hatermedia/clipper.git

Step 2 — Dry-run the whole folder

Point Clipper at the folder where ShadowPlay saves its captures. The default is usually Videos\NVIDIA or a custom folder you chose in the overlay.

clipper --input "D:\ShadowPlay" --dry-run

A dry run writes timestamps, a score breakdown, and preview JPEGs into trimmed\previews. It does not render video. Read the report before you commit to a batch:

demo_gameplay.mp4  0:46.021  1280x720  30.0fps
  01  0:12.500 -> 0:18.500    6.0s  score 100  [audio + motion]
  02  0:30.250 -> 0:36.250    6.0s  score 100  [audio + motion]

The score is a relative confidence signal, not a percentage of “goodness.” A clip with only loud audio should score lower than one where audio and motion agree.

Step 3 — Tune the detector for your game

The defaults are deliberately middle-of-the-road: 8 seconds before the peak, 5 seconds after, sensitivity 0.5. Two knobs matter most:

  • Sensitivity (--sensitivity): higher finds more moments and more false positives.
  • Padding (--pre, --post): how much run-up and aftermath you want around the peak.

For fast shooters, a balanced starting point is:

clipper --input "D:\ShadowPlay" --dry-run --sensitivity 0.6 --pre 5 --post 4

For quiet tactical games where the action is visual but not loud, raise the motion weight:

clipper --input "D:\ShadowPlay" --dry-run --sensitivity 0.65 --visual-weight 0.7 --audio-weight 0.3

For racing or sports where the engine/commentary is constant, lower the audio weight and rely more on visual deltas.

Step 4 — Export the highlights

clipper --input "D:\ShadowPlay" --output "D:\Highlights"

By default Clipper uses FFmpeg stream copy (-c copy). It is effectively instant and does not touch quality. The trade-off is keyframe alignment: a copy clip can start slightly before the requested timestamp. That is usually desirable for highlights because you get extra run-up.

If you need exact edges for a montage, re-encode:

clipper --input "D:\ShadowPlay" --output "D:\Highlights" --reencode --encoder h264_nvenc

NVENC is fast on NVIDIA GPUs. If the encoder is listed but unusable on your machine, Clipper retries with libx264.

Batch behavior worth knowing

  • Supported inputs: .mp4, .mkv, .mov, .avi.
  • Use --recursive for nested folders.
  • Output defaults to ./trimmed; reports are written as clipper-report-*.json.
  • Overlapping windows merge, so a long fight stays one clip instead of being chopped into fragments.
  • Clips are capped by --max-clips (default 30) and filtered by --min-clip (default 3s).

Rights check: ShadowPlay captures can include copyrighted music, voice chat, or other people’s audio. Clipper only edits; it does not grant publishing rights. Use footage you own or are authorized to publish.

Prefer a UI?

Run clipper ui. It starts a local FastAPI server at 127.0.0.1:8765 with a folder browser, sensitivity slider, preview thumbnails, and batch export progress. Nothing is uploaded.

FAQ

Does Clipper upload my ShadowPlay clips?

No. Analysis and export run locally. The web server binds to localhost by default.

Will stream copy miss the start of a fight?

It can start on the previous keyframe, which means extra run-up, not less. If the extra footage bothers you, use --reencode.

Can it handle 4K or long VODs?

Yes, but analysis is decode-bound. The visual pass uses a 320px / 4fps proxy, so it is much cheaper than decoding every frame at full resolution. Long 4K sessions still take time.

What if the folder contains non-gameplay clips?

Clipper does not understand context. A loud menu, a shout, or a music-heavy intro can score. Review the dry-run list; it is designed for exactly that.
