Where does ShadowPlay save highlights?

NVIDIA’s capture tool has changed names and UI several times, but the files still land in a normal folder on disk. Once you find that folder, you can point a local trimmer at it and stop scrubbing manually.

Find the capture folder

In the current NVIDIA App (or GeForce Experience on older installs), open Settings → Capture (sometimes “Video capture” or “Recordings”). The UI shows a Capture folder path and a Gallery location. The default is usually under your Videos library:

C:\Users\<you>\Videos\Captures
C:\Users\<you>\Videos\NVIDIA

If you changed it, the settings panel is the source of truth. Do not guess based on an old forum post; NVIDIA has moved this more than once.

What the files look like

Typical names:

Game Name 2026.11.23 - 14.32.10.01.mp4
Game Name 2026.11.23 - 14.32.10.01.DVR.mp4

They are usually H.264 MP4 with AAC audio. The exact codec, bitrate, and keyframe interval depend on your settings and GPU. Clipper handles .mp4, .mkv, .mov, and .avi.

Batch trim the folder

Dry-run first. It writes timestamps, previews, and a JSON report without rendering video:

clipper --input "C:\Users\<you>\Videos\Captures" --dry-run

If your captures are nested by game or date, add --recursive:

clipper --input "C:\Users\<you>\Videos\Captures" --recursive --dry-run

Review the preview frames. Then export:

clipper --input "C:\Users\<you>\Videos\Captures" --output "D:\Highlights"

ShadowPlay-specific tuning

  • Instant replay clips can be short and start mid-action. Use a smaller --pre, e.g. --pre 4.
  • Long manual recordings can have a lot of downtime. Raise --min-clip to 4–6 seconds.
  • Quiet tactical games: raise the motion weight, e.g. --visual-weight 0.6 --audio-weight 0.4.
  • Loud music/voice chat: raise the motion weight so the detector does not chase every voice peak.
clipper --input "C:\Users\<you>\Videos\Captures" --recursive --dry-run --pre 4 --post 3 --min-clip 4 --visual-weight 0.6 --audio-weight 0.4

Why a clip starts before the timestamp

Default export uses stream copy, which starts on the nearest keyframe. That can add a second or two of run-up. It is usually good for highlights. If you need exact edges, add --reencode.

clipper --input "C:\Users\<you>\Videos\Captures" --output "D:\Highlights" --reencode --encoder h264_nvenc

Troubleshooting

ProblemFix
Folder is emptyCheck NVIDIA App → Settings → Capture for the current path; instant replay may be off.
Clips have no audioCheck the capture audio device; Clipper warns and falls back to visual-only.
Files are not detectedCheck the extension and permissions; try --recursive.
Clip starts earlyStream-copy keyframe behavior; use --reencode.
HDR looks washed outRe-encode to SDR H.264; stream copy preserves the source’s color metadata.

Skip the install

The native Windows build bundles Python, PySide6, and FFmpeg. Unzip it, run Clipper.exe, and point the folder picker at your captures.

FAQ

Does Clipper delete or move my captures?

No. It reads the source and writes new files to the output folder.

Can it trim while ShadowPlay is still recording?

Do not process a file that is still being written. Wait until the recording finishes and the file is closed.

Does it work with NVIDIA App and GeForce Experience?

Yes. The capture folder is just a folder; the tool does not care which app wrote the file.
