Privacy
-------
All audio, video, OCR, acoustic analysis, and local llama.cpp or explicitly
configured local-server inference run on the user's machine. Clipper does not
upload footage. GitHub is contacted only for the user-initiated or scheduled
update check, and the configured model hosts only when the user downloads a
runtime or model.
